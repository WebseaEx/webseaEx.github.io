    Error Codes

    HTTP Status Codes

    errno errmsg Description
    200 OK Request succeeded
    301 Moved Permanently Permanent redirection
    302 Found Temporary redirection
    304 Not Modified Resource has not been modified
    403 Forbidden Access is denied
    404 Not Found Resource or API endpoint does not exist
    429 Too Many Requests Request rate limit exceeded
    503 Service Unavailable Service is temporarily unavailable (maintenance or overload)
